⚠ "Unrecognized app" / "unknown sources"?

That is normal — the app is not code-signed yet. On Windows: More info → Run anyway. On Android: allow install unknown apps for your browser or Files, then tap the APK. Same file you downloaded here.

🔋 Mining stops when the screen is off?

Android freezes background apps it is allowed to freeze, and a frozen app cannot mine. Let goblingames run without battery restrictions: Settings → Apps → goblingames → Battery → Unrestricted.

On some phones that is not enough — Xiaomi/Redmi, Infinix, Tecno, ZTE, Oppo/Realme and friends need Autostart enabled for the app as well (Settings → Apps → goblingames → Autostart / "Start in background"). The app asks for the battery permission once, and the mining panel shows a line with a button while the restriction is on. A phone left restricted mines for about an hour and then goes quiet until you touch it.
